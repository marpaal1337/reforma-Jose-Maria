⚠️ No se especifica el **tipo de lana mineral** (densidad). Para un buen aislamiento acústico se recomienda lana de roca de alta densidad (>60 kg/m³).

| Resistencia al fuego | ~60 min | ~60 min |
| Capacidad de carga | Alta ✅ | Limitada (requiere refuerzos) |

## 4. Pavimentos

### 4.1 Sistema de pavimento propuesto (Cyss v2.0)

| Capa | Cyss v2.0 | ¿Incluida? |
|---|---|---|
| Pavimento existente | No se demuele (solo balcón: 2,6 m²) | ❌ Se conserva |
| Base niveladora de mortero ligero | RSB020 — **eliminada en v2.0** (estaba en v1) | ❌ **NO** |
| Adhesivo cementoso | Incluido (RAG012 / RAG012c) | ✅ |
| Pavimento porcelánico 25×150 + 60×120 | Suministro y colocación | ✅ |
| Junta de dilatación perimetral | No especificada | ❌ **NO** |
| Rodapié | No incluido | ❌ **NO** |

**Esquema del sistema completo (recomendado)**:

```
                        ┌─────────────────────┐
                        │  Pavimento            │  (1-1,5 cm)
                        ├─────────────────────┤
                        │  Adhesivo cementoso   │  (0,3-0,5 cm)
                        ├─────────────────────┤
                        │  Base niveladora      │  ← CAPA FALTANTE
                        │  mortero ligero       │  (3-6 cm según desnivel)
                        ├─────────────────────┤
                        │  Pavimento existente   │  (se conserva)
                        └─────────────────────┘
                        Junta perimetral (5 mm)  ← CAPA FALTANTE
```

**⚠️ Riesgos**:
1. **Falta de base niveladora**: Si el pavimento existente tiene desniveles (habitual en viviendas antiguas), el nuevo pavimento puede quedar irregular. En el peor caso, podría agrietarse por falta de apoyo uniforme.
2. **Cotas de puertas**: Si se añade la base de mortero (3-6 cm) + pavimento (1-1,5 cm), la cota del suelo sube 4-7 cm. Esto puede afectar a:
   - Altura libre de puertas existentes
   - Altura de paso a balcón
   - Encuentro con el ascensor (umbral)
3. **Rodapié**: No incluido. ¿Se reutiliza el existente? El rodapié de terrazo existente (63 ml) se levanta (partida DRS011) pero no se repone.

**Recomendación**: 
- **Preguntar a Cyss** por qué se eliminó la base de mortero ligero en v2.0
- Si el pavimento existente está en buen estado y nivelado, se puede prescindir de la base
- Si hay desniveles > 5 mm en 2 m, **es necesario nivelar**
- Solicitar inclusión de rodapié (presupuesto estimado: 63 ml × ~8-12 € = 504-756 €)
